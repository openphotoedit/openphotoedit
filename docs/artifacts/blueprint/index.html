We tore down Photoshop 27.10 and Camera Raw 18.6, the leading rival editors, 30+ open-source projects and the local AI models that could replace cloud features. No open-source editor combines faithful PSD round-trip with credit-free AI in a browser tab. That gap is worth building for, but as a sequence, not a clone.我们逐项拆解了 Photoshop 27.10 与 Camera Raw 18.6、主要的竞品编辑器、30 多个开源项目，以及能替代云端功能的本地 AI 模型。结论是：目前没有哪个开源编辑器能在浏览器标签页里同时做到 PSD 往返保真和不扣积分的 AI。这个空白值得去填，但要分步推进，而不是照搬一个 Photoshop。

Why build it为什么要做

The meter is the incumbents' structural weakness计费表是现有厂商的结构性弱点

Photoshop's single-app plan costs $22.99 a month and includes 25 generative credits, about two premium generations. The free alternatives each trade something away: Photopea carries ads and charges credits for AI, Affinity needs a Canva login and puts all its AI behind Canva Premium, and GIMP has no web version and no AI.Photoshop 单应用套餐每月 22.99 美元，只含 25 个生成积分，大约够生成两次高级内容。免费替代品各有取舍：Photopea 有广告，AI 还要扣积分；Affinity 必须登录 Canva，所有 AI 功能都锁在 Canva Premium 里；GIMP 没有网页版，也没有 AI。

Every incumbent that computes AI in its cloud has to charge for it. Removal, masking, cutout, upscale, denoise, culling and retouch all run on the user's own GPU at no cost to us, so they can be unlimited forever.凡是在自家云端跑 AI 的厂商，都不得不收费。而去除、蒙版、抠图、放大、降噪、筛片和修图都可以在用户自己的 GPU 上运行，我们不承担任何成本，所以可以永久不限量。

  • PSD round-trip is the moatPSD 往返保真是护城河

    A reader and writer that survive real Photoshop 2020–2026 files, including a flattened composite our renderer draws to match Photoshop. It is corpus-driven drudgery a weekend project cannot reach.读写器要扛得住 Photoshop 2020–2026 的真实文件，连拼合合成图也要画得和 Photoshop 一致。这是靠文件语料库一点点磨出来的苦活，周末项目做不到。

  • AI with no creditsAI 不扣积分

    That is Photopea's premium tier, Affinity's Premium tier, Lightroom's culling credits and Evoto's per-export fee, all given away, because the compute is the user's own GPU.相当于把 Photopea 的高级版、Affinity 的 Premium、Lightroom 的筛片积分和 Evoto 的按导出计费全部免费送出，因为算力来自用户自己的 GPU。

  • Prompt edits become sliders提示词编辑落到滑块上

    The prompt bar writes visible slider changes you can adjust: a rule parser in 8 languages in P1, a local LLM in P3. Photoshop's AI Assistant and Lightroom meter this.提示栏会把需求转成看得见、还能再调的滑块变化：P1 用覆盖 8 种语言的规则解析器，P3 接入本地 LLM。Photoshop 的 AI Assistant 和 Lightroom 在这件事上都要计费。

Profiles are views of one document. Every Lite step is a real adjustment layer, mask or pixel layer underneath. Open in Pro shows those layers exactly; nothing is flattened. The profile changes the tool registry, panel layout and defaults, never the file.两个配置只是同一份文档的不同视图。Lite 里的每一步，底层都是真正的调整图层、蒙版或像素图层。在 Pro 中打开会原样显示这些图层，不做任何拼合。切换配置只改变工具集、面板布局和默认值，从不改动文件。

Rust everywhere. The engine compiles to wasm and runs in a worker in a browser tab, or runs as one native binary: openphotoedit serve opens the same UI at 127.0.0.1 with native AI and no 4 GB memory cap.全栈 Rust。引擎可以编译为 wasm，在浏览器标签页的 worker 里运行；也可以是一个原生程序：openphotoedit serve 在 127.0.0.1 打开同一套界面，启用原生 AI，没有 4 GB 内存上限。

Open decisions待定事项

Five decisions for you需要你拍板的五件事

  • Name名称Trademark risk商标风险

    Settled. The working name "OpenPhotoshop" used Adobe's registered mark, which invites a GitHub DMCA/trademark takedown, store rejection and a domain dispute. The product is now OpenPhotoEdit: folder, binary, project format and accent-slot row all moved with it.已确定。原暂定名“OpenPhotoshop”使用了 Adobe 的注册商标，会招来 GitHub 的 DMCA/商标下架、应用商店拒审以及域名争议。产品现名 OpenPhotoEdit：目录、可执行文件、项目格式和配色槽记录都已随之更名。

    Next下一步Register the domain and the GitHub account under the new name before the first push.首次推送前，用新名称注册域名和 GitHub 账号。

    Domain and account still to register域名与账号尚未注册

  • Licence许可证

    AGPL lets us use rawler, libheif and darktable/RawTherapee maths. Permissive for everything would force clean-room RAW, demosaic and retouch code.AGPL 允许我们使用 rawler、libheif 以及 darktable/RawTherapee 的算法。如果全部采用宽松许可，RAW、去马赛克和修图代码就只能净室重写。

    Recommend建议AGPL-3.0-or-later for the app; publish editor-psd and editor-tiles as MIT/Apache to attract contributors.应用采用 AGPL-3.0-or-later；editor-psd 和 editor-tiles 以 MIT/Apache 单独发布，吸引贡献者。

  • Which Pro first先做哪个 Pro

    PSD is the moat and shares all of Lite's engine; the photographer pipeline adds rawler and library work on top.PSD 是护城河，而且完全复用 Lite 的引擎；摄影师流程还要额外加上 rawler 和图库功能。

    Recommend建议P2 "open Photopea" before P3 Photographer. The reverse is defensible if the first Pro users are photographers.先做 P2“开源版 Photopea”，再做 P3 摄影师版。如果首批 Pro 用户是摄影师，反过来也说得通。

  • LLM in Lite 1.0Lite 1.0 是否带 LLM

    Whether P1 includes the optional 1.1 GB LLM prompt bar or ships rules-only.P1 是带上可选的 1.1 GB LLM 提示栏，还是只用规则解析发布。

    Recommend建议Rules-only in P1. Add the LLM in P3, after the 300-command evaluation.P1 只用规则。等 300 条指令的评测完成后，在 P3 加入 LLM。

  • Grey-zone models灰色地带模型

    BiRefNet_lite (trained on DIS5K) and GFPGAN (trained on FFHQ) have permissive weights but non-commercial training data.BiRefNet_lite（用 DIS5K 训练）和 GFPGAN（用 FFHQ 训练）的权重许可宽松，但训练数据限制商用。

    Decide待决Ship them as optional downloads with a note, or hold them back. Either way the decision gets recorded.作为附带说明的可选下载提供，或者暂不提供。无论选哪种，都要记录在案。
